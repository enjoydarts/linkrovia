# Cloudflare plans and costs

Start with Workers Free, a D1 database, and a passkey. You can create and use short links while click analytics is disabled. Enable Analytics Engine when you are ready to collect clicks. Cloudflare measures each service separately across the account. Check your account’s available capacity if it hosts other applications.

Cloudflare’s published prices and limits were checked on **November 26, 2026**. Figures are in USD. Check the linked product pages and your Cloudflare dashboard before changing plans.

## Check a CPU limit error

In Cloudflare, open **Workers & Pages**, select the Linkrovia Worker, and open **Metrics → Errors → Invocation Statuses**. If a password or scheduled request returns error `1102`, check whether the outcome was **Exceeded CPU Time Limits**. The same error code can also refer to memory. Workers Logs shows CPU time and wall time separately. Test sign-in with a passkey or follow an ordinary short link to check the basic flow. Use Workers Paid if your installation needs the higher CPU allowance for password operations or scheduled jobs. [CPU usage and errors](https://developers.cloudflare.com/workers/platform/limits/#cpu-time)

## How the AI budget relates to your bill

The **AI costs** chart and monthly budget use Linkrovia’s estimated model usage at Cloudflare’s published rates before the daily free allocation. Linkrovia only sees usage from this installation. Use the Cloudflare dashboard for account-wide usage and actual charges. The Linkrovia AI budget covers model calls from this installation. Workers, D1, and the optional metadata service have their own Cloudflare usage and charges. [AI usage and budget](analytics.md#enable-ai-assistance)
